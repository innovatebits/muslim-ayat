# Muslim Ayat

A Quran-first reading experience where the Quran remains accessible without signing in. Accounts are reserved for personal features such as bookmarks, notes, saved preferences and cross-device reading progress.

## Product principles

- **Read without an account:** Quran reading is public.
- **Personalize with an account:** sign-in is required only for account-backed personalization and synchronization.
- **Respect the text:** Quran content, translations, tafsir and recitations require clear source, edition, attribution and licensing.
- **Build progressively:** start with a reliable public reader, then add personal features and offline synchronization.
